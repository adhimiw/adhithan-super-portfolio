# Adhithan Super Portfolio — Neural Lab

Fresh static portfolio. Three.js neural particle field + Anime.js timelines. No backend.

## Run
```
npm install
npm run dev
```

## Build (Render Static)
```
npm run build
```
Publish `dist/`. No env vars needed.

## What changed vs old
Old `Adhithan-Dev_portfolio` was React + MUI + Express + Mongo with cold starts.
This is Vite + vanilla + Three.js + Anime.js, data in `src/data.js`, assets procedural + 2 reused Cloudinary images.

## Skills used
frontend-design, taste-skill (6/5/4), 3d-web-experience SceneManager pattern, awesome-frontend-resources patterns.
